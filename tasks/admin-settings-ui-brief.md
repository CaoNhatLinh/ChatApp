# Admin settings: compact, visual operation

Scope: admin navigation/chrome, overview entry and application settings only.
Preserve Signal Relay tokens, real permissions and canonical save/retry/audit.
No new provider, marketing claims, invented activity or redesign of chat.

## Direction contract

THESIS: reach a useful control immediately; remove the repeated admin hero,
permission-count cards and breadcrumbs above every workspace.
OWN-WORLD: existing ink/pale canvas, orange only for selection/actions, shared
BrandMark, Lucide, compact sans, quiet divided rows and protected-focus dialogs.
STORY: scan saved settings, choose Edit, change a value, explain once, save.
FIRST VIEWPORT: compact navigation/title, two setting rows and a responsive
community access diagram driven only by the two validated saved values.
FORM: user-directed hybrid; code-led distillation, no seed/identity replacement.
FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## State matrix

| Surface | Main task | Required states / narrow behavior |
| --- | --- | --- |
| Admin shell | Choose workspace | permission-gated destinations, compact mobile select, no hero/stats on child screens |
| Settings list | Read saved policy | loading, failure/retry, forbidden, two current values; never fabricate defaults |
| Setting dialog | Edit/save one value | initial, dirty, invalid, pending,409+retained draft/reload, uncertain+same-command retry, confirmed current authority |
| Dialog exit | Return without losing work | Escape/close retain draft in mounted row; discard is explicit; busy blocks close; focus returns to Edit |
| App-owned exit | Leave administration intentionally | Stay/Escape preserves memory; clear/draft/busy/uncertain priority, honest possible-commit warning, no implicit save/retry; browser Back/Forward/reload recovery remains separate |
| Preview | Understand new-community access | saved enabled/paused state and member limit; keyboard-triggered replay, hover motion, reduced-motion static equivalent |

warning exists; full SPA-route leave/reload-persistent retry is not claimed.
