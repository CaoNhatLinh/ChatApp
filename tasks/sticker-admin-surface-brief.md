THESIS
Sticker publishing is deliberate: browse, edit a draft, review artwork, then publish.

OWN-WORLD
Extend the existing Signal Relay operator workspace, not the chat shell or a new identity. Neutral theme tokens, existing controls, restrained action accent.

STORY
Global operators select a pack, manage its artwork and leave an audit reason. No automated safety claim.

FIRST VIEWPORT
A named catalog, real loading/error/empty states, a clear create action and selectable pack rows. Desktop reveals an adjacent editor; mobile follows one readable column. Inline feedback replaces toasts.

FORM
Local extension, no concept seed. Selection and pending states are the signature interaction; short existing control transitions respect reduced motion. Drafts survive errors; uncertain retries reuse commands.

FINISH
unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
