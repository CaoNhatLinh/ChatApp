# Admin settings: image-led, without duplicate controls

Scope: existing `/admin` application settings. Local composition replacement;
preserve Nối identity and all server contracts. No backend/provider changes.

Direction: one authored community illustration on the app canvas, beside the
two actual saved-setting controls. Remove the separate duplicate preview panel,
its duplicate values/actions and separator rows. On mobile, actions precede art.
Artwork is illustrative, not real members, usage or evidence of a live service.

Interaction: existing protected-focus editors remain authoritative. Numeric
preset buttons change only the draft, never save. Hover/focus gives a short
artwork response; saved creation state controls the open/paused symbol. No idle
animation, fake counters or success toast. Failed artwork has a local fallback.

Acceptance: both actions in the first viewport; light/dark at
320/768/1024/1440; reduced motion; illustration loaded/failure; keyboard entry,
focus return, draft retention, valid presets, explicit reason/save, stale-write,
lost acknowledgement/exact retry, permission loss and refresh regression.
Use production browser UI with controlled transport; this is not live Cassandra
or whole-app acceptance. No commit/push or new UI dependency needed.

Asset: generated with the built-in image tool; provenance is recorded under
`docs/brand/`. Only the optimized transparent WebP is shipped.

## Direction contract

THESIS: One illustrated setting composition, not a list plus duplicate preview.

OWN-WORLD: Nối app tokens and type; authored clay/paper community artwork sits
on the existing canvas, with restrained orange/teal/periwinkle material.

STORY: Read saved access/capacity, open the real editor, choose a draft and save.

FIRST VIEWPORT: Desktop art at left, two compact unboxed controls at right.
Mobile controls come first, a smaller illustration follows. No separator rows.

FORM: Local extension; no concept roll/new identity. One short focus/hover lift,
reduced-motion fallback. Presets never bypass reason, validation or save.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
